# Code of Conduct

## Our standard

Be respectful. Disagree about code, not people. No harassment, personal
attacks, or discriminatory language in issues, PRs, discussions, or any
other project space.

## Scope

Applies to all project spaces (GitHub issues/PRs/discussions) and any other
venue where you're representing the project.

## Enforcement

This is a small, single-maintainer open-source project — there is no formal
enforcement committee. Report unacceptable behavior to
**mullassery@gmail.com**. The maintainer will review reports and may warn,
edit/remove content, or block a contributor from the project, at their
discretion, with no guaranteed response time.
